# Saiyan Survivor Android

Prototipo Android estilo survivor con temática anime inspirada en artes marciales y energía.

## Controles
- Joystick táctil: mover personaje
- Ataque automático al enemigo más cercano
- Subidas de nivel y mejoras automáticas
- Cofres con poderes
- Boss progresivo

## Compilar APK
El workflow de GitHub Actions genera un APK debug automáticamente en cada push a `main`.
El APK queda disponible como artefacto `SaiyanSurvivor-debug-apk` dentro del run de Actions.

Versión: 0.1.0
